# Calculadora JS com TDD

Calculadora simples desenvolvida com JavaScript, Vue.js e testes automatizados.

## Funcionalidades

- ✅ Soma
- ✅ Subtração
- ✅ Multiplicação
- ✅ Divisão
- ✅ Interface reativa com Vue.js

## Como usar

Abra o arquivo `index.html` no navegador.

## Testes

Execute os testes com:

```bash
npm test
```

## Tecnologias

- HTML/CSS
- JavaScript
- Vue.js 2.7
- Jest
